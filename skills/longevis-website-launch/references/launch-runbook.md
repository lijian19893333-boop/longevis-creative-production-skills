# 上线执行手册

[English version](launch-runbook.en.md)

本手册描述可复用步骤，不含可直接套用的生产变更命令。先按当前项目和授权裁剪范围；相关服务有足够的连接器/API/CLI时优先使用，浏览器登录与宝塔界面作为实际需要时的路径。

## 1. 识别现状与本次变更

建立一份简短发布记录：项目、当前公开版本、目标版本、域名、构建路线、服务工作目录、静态资源目录、数据和私有媒体位置、备份/回退点。没有Git commit时，用包SHA-256、文件清单、关键源码哈希与切换时间定位版本。

按任务选择：纯内容优先已有CMS草稿→预览→发布；源码改动走构建和候选发布；域名切换沿用已验收版本与数据；数据库迁移单独核对目标与授权。用户授权发布不意味着需要重置或迁移数据库。

先把已知公开页面、联系入口、后台权限和发现入口作为基线。检查工作区是否有其他待发修改，发布只纳入本次确认范围。

## 2. 首页整合和事实核对

将已确认首页接入完整网站，保留导航、页脚与既有路由。核对页面与具体产品、型号、三维及联系目标的映射；不把历史设计或工程模型当作现售产品。

三维按需打开；弹窗打开时暂停场景视频，关闭后按用户原暂停选择恢复。手机布局同时保留画面比例和可读正文。图片区分纯产品图、场景图和案例实拍，设备图不拉伸。

技术参数、项目交付状态和获奖信息分别依据最新确认与来源。缺少型号、收益或具体性能时保留未确认状态；案例实拍与主办方奖项记录不扩展成型号认证或疗效证明。

## 3. 媒体与弱网

先测：原片大小/编码、封面大小、服务器带宽、Range响应、是否真实解码、可见场景请求和失败回退。用受控网络条件检查首屏，不能靠“我本地很流畅”排除带宽瓶颈。

- 封面、文字、导航先可用；活动场景或临近视口再加载，默认不并发预取全部视频。
- 保留母版。质量要求允许时另做兼容网页副本，核对构图、比例、清晰度、音轨、时长和实际播放；明确需要降低分辨率时按用户已确认范围执行。未授权降质时先用加载调度、封装faststart、缓存或受控分发方案。
- 自动预取任务可随离屏停止。若产品需求是“用户主动下载跨场景保持”，区分主动任务与自动任务；支持可见进度、取消/继续、有限并发，不把该保证扩展到关闭页面或独立路由跳转。
- 自动播放遵守浏览器策略：默认有声需求被拒时回退静音并显示“开启声音”；实际有声时显示“静音”。用户主动静音/暂停优先于异步完成与场景切换。
- 公网核对Range 206、总长度，发布传输副本以整片SHA-256比对；抽样分段响应只证明该段可取，不等于整片一致或连续播放。
- CDN只有配置完成、媒体URL实用且请求与播放测试通过后才记为启用。控制台未启用或仅有方案时记为待配置；不要自动购买或启用付费服务。

## 4. 本地与服务器隔离验收

先检查当前 `package.json`、README 与部署文档，发现实际支持的检查、目标构建、启动与巡检命令。不要假定项目提供特定脚本。

静态网站只有在确认目标是静态导出且存在对应入口后才发布静态目录。SSR 网站核对服务器入口、Node 运行时和托管进程；普通开发构建不能代替生产目标构建。两类产物同时存在时，以项目脚本和实际启动入口为准。依赖不在 PATH 时先发现已有运行时，不盲目重装依赖。

候选站使用独立发布目录、仅回环监听的独立端口，以及当前生产数据库/私有媒体的受限副本。生产数据副本仍视为私密；不能公开、打入发布包或当作测试数据交付。Mac依赖不能直接作为Linux原生依赖部署，复用已验收的兼容依赖或在目标环境构建。

检查桌面和390px布局、首页场景、产品和工具路由、联系入口与后台鉴权。390px桌面模拟与实体手机分别报告。整站巡检包含内部链接、canonical、原图与优化图的GET类型及逐跳协议；HTTPS图片重定向到HTTP也计为失败。页面数变化核对发布状态与译文版本，解释后再判断。

## 5. 备份、切换与回退

按当前实际托管方式执行；相关运维 Skill 已安装时可参考，但本手册不以其他 Skill 为必需依赖：

1. 备份数据库一致性快照、私有媒体、env、Nginx/systemd和相关证书，核对备份可读取及权限；旧应用目录保留。
2. 上传到独立暂存目录，核对包SHA-256、文件清单、目标身份和公共文件父目录权限。暂存成功后仍停留“已上传”状态。
3. 候选站验收通过再切换正式服务与Nginx静态根，语法检查后reload；避免宝塔Node项目与systemd重复占端口。读取最终生效配置而非只看某个drop-in文件。
4. 不用本地演示库覆盖正式库、不自动播种；代码回退默认保留上线后新增的数据。恢复旧数据须单独确认目标和时间。
5. 用公网请求比对新JS/CSS文件名、字节哈希、资源清单与真实页面；防止旧长缓存继续运行旧逻辑。保留已打开旧页面后续所需资源。

优先用源代码生成已验收构建。确需沿用服务器产物做最小运行时补丁时，核验精确前置哈希，使用独立副本，同步源码；检查硬链接/COW，写入前断开共享，避免补丁同时改坏当前与回退版本。客户端依赖引用、资源长度/ETag同步更新并做公网字节核对。

若发布期间当前版本或配置已被别的更新改变，停止本次切换，重新对照差异，不能覆盖后续工作。回退脚本同样检查当前身份；旧回退命令不是通用命令。没有生产回退演练时，写“已保留回退点/隔离验证”，不能写“生产恢复已验证”。

## 6. 正式域名、证书和旧入口

宝塔/Nginx负责站点、TLS和反向代理；DNSPod或当前DNS服务负责解析。先分别观察两边。

- 核对根域、www、旧子域的权威DNS和至少一个独立公共解析结果；必要时直连新IP带Host/SNI对比，确认旧官网来自旧服务器还是缓存。
- 用户提供的证书检查SAN、有效期、链、公私钥匹配与公网指纹；密钥仅存在受限私有路径。根域/www 证书不自动覆盖其他子域。
- HTTP→HTTPS、裸域→规范www、旧域→正式域都保留路径和查询参数；旧HTTPS入口先有自己的有效TLS再跳转。仅服务器写了308而旧域NXDOMAIN时，兼容入口仍未完成。
- 统一canonical、Open Graph、JSON-LD、robots、sitemap、llms及必要环境值；网站原有产品URL尽量保留，确需变动设置明确重定向。
- 修改DNS前保存记录快照，只改本次目标，核对原邮件等业务记录未受影响；切换后取权威解析、公共解析、普通公网和浏览器结果。分开记录传播中的短暂旧缓存与最终证据。

## 7. 统计、咨询、SEO/GEO与持续维护

统计脚本每文档一次，公开页加载，管理/API排除。核对正确ID、脚本与回传响应；报表是否入库要进后台单独验证。

咨询 UI 与统计联动时测试真实点击命中。移动端隐藏规则只作用于已确认断点，复测桌面入口及网站自有联系方式。欢迎语出现不等于每条访客消息、离线、排队或超时自动回复已配置；用户未要求时不发送客服测试消息或启用付费机器人。

SEO/GEO先确认服务端可见正文、标题、描述、H1、结构化数据、robots、sitemap、llms/品牌事实页与双向内链，再处理采购问题、画册资料、真实案例和外部证据。FAQ正文与JSON-LD同源；旧译文需要更新时退出地图，不继续展示为新事实。

提交/抓取/收录/排名/AI引用分别记录：提交回执只证明接收；机器人抓取核验身份与HTTP；品牌词搜到一次不外推所有关键词；AI测试记录平台、时间、问题、来源URL和账号历史干扰。遇验证码记为待用户在场，不计有效样本。

发布后读取服务健康、关键路径、静态资源、后台401、未知页404、表单/咨询与双端视频。仅在授权范围内进行真实写入验证，避免创建客户误认的线索。记录当前故障及后续检查，不把本次备份存在描述为自动异地备份、续期或告警已经配置。
