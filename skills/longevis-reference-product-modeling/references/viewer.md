# 本地三维预览

优先复用已有查看器，避免每轮增加页面和端口。新项目可复制本 Skill 的 `assets/viewer/` 到项目的 `preview/`，把普通、自带贴图的 GLB 放为 `preview/model.glb`，保留 vendor 目录完整。`index.html` 默认提供英文界面，`index.zh-CN.html` 提供完整中文界面，均可切换语言；`index.en.html` 保留为英文兼容入口。

从 Skill 目录运行：

```sh
python scripts/serve_viewer.py --directory ./example-project/preview
```

Windows 使用 `py` 或本机可用的 Python 命令。程序会打印实际 `http://127.0.0.1:端口/index.html`，保持服务进程运行；关闭进程后链接自然失效。项目已有可用端口时用 `--port 端口` 固定入口，端口冲突不要直接杀掉未知进程。

本地链接只能在运行服务的那台机器打开。给别人发查看器时，连同 GLB、HTML、JS 和 vendor 一起打包，由对方在本机启动；不能只发送你的 127.0.0.1 地址。模板也支持在页面中从本机选择 GLB，但不替用户上传到第三方。

## 模板范围

- 拖动旋转、缩放，六方向视角、重置、自动旋转。
- 列出模型自带的动画，支持播放/暂停和拖动进度。
- 模型刷新、加载错误说明；缺动画不伪造“开门”。
- 自带 model-viewer 4.0.0 本地模块及上游许可证；普通 GLB 无需 CDN。
- 不包含 Draco/Meshopt/KTX2 解码器。需要这些压缩格式时按真实依赖补齐，或先导出普通 GLB。

这是基础查看器，不是完整 CAD 编辑器。多门独立按钮、部件选择/隐藏、剖切、爆炸图需要结合当前产品节点和动画实现；不要把“动画列表可选”宣传为完整拆装功能。

## 交付前实际检查

确认服务监听、HTML/JS/GLB 能加载；在浏览器看到真实模型。测试视角、旋转、动画中间帧、末帧、切换动画、刷新和模型更换。导出的是新版本不代表浏览器已显示新版本，核对文件名/哈希与缓存。

在支持侧栏的宿主中打开真实预览页；工具返回 queued 时仅说明已请求打开，不说已经显示。用户只看到工具截图或静态图片时仍未满足交互预览要求。
