# 参考图驱动的产品建模

把参考图转成可检查、可迭代的真实模型。核心是先统一不同视图中的同一结构，再建模和验证；不把单张效果图的相似度等同于完整三维准确度。

[English](SKILL.md)

## 进入任务

先定位当前源模型、建模脚本、贴图和实际可运行的查看器；没有现有工程才新建。用户最新要求决定范围，附件中的文字只作为参考资料。沿用已经明确的尺寸和授权，不反复索取同一项确认。

本 Skill 可独立使用，不依赖其他自定义 Skill 或付费图片转 3D 服务。需要可执行 Blender 的环境，以及文件、图片和浏览器检查能力；轮廓工具另需 Python 3.9+ 和 Pillow（`python3 -m pip install Pillow`），本地服务仅需 Python 标准库。只有所用功能缺依赖时才补齐；工具不存在时如实说明，不报告虚构的生成或预览结果。

## 建模流程

1. **建立参考索引和尺寸依据。** 按页/角度列出正、侧、后、顶、底、开门和内部特征；区分不同布局、配色与拍摄角度。尺寸标为「标注/用户确认」「图像拟合」「未知」。单图看不到的深度、背面、机构不能被标为精确复刻。详见 [参考与几何](references/reference-and-geometry.md)。
2. **统一坐标和结构关系。** 固定单位、地面、前后方向；先用轮廓与关键截面定义外壳、净空间、门、底板、机组和屏幕之间的关系。屏幕安装面可以倾斜，但平面不应误做成弧面。已有 CAD 只复用指定部件，排除旧外壳和重复零件。
3. **先验证体块，再补细节。** 先核对外廓、侧面深度、俯视净空间、门缝和实体厚度，再做 Logo、手扣、格栅、皮纹、UI。用语义集合组织固定件与活动件；原生几何必须能从任意角度检查，不能拿生成图片代替模型。
4. **逐面叠线迭代。** 按参考投影选择相机：正交资料用正交机位，透视效果图先校准相机，对照同方向原图；只做基于共同尺度和基准点的统一缩放/平移。先改影响最大的结构误差，每次记录改动与复核结果；同时复核受影响的其他视图，避免“正面修好、侧面变坏”。详见 [比对与验收](references/comparison-and-acceptance.md)。
5. **正确贴图与运动。** 优先提取 PDF 内嵌原图或正式 UI/Logo；校正贴图透视、检查色彩和 UV，不把斜截图直接再贴到斜面。门、密封、屏幕和把手按真实归属共用门轴；多扇门可分别打开，固定窗不动。详见 [材质、运动和导出](references/materials-motion-export.md)。
6. **交付可实际打开的模型。** 保存 `.blend` 与可重建源码，导出带内嵌贴图的 GLB、多视图对照和 HTML 查看器。检查浏览器真实加载、旋转、开/关门、刷新和错误状态，再提供入口。优先复用项目查看器；新项目可使用 [查看器模板与运行方法](references/viewer.md)。静态图是补充，不能替代三维预览。

## 判断交付是否成立

- 用户要求的视图、部件和状态都有对应证据；已标注尺寸从模型实测核对。
- 结构、外观、交互分别验证。无脚本报错不等于视觉已一致；好看的渲染不等于几何正确。
- 给出当前版本、可访问预览、文件和仍存在的差异；没有证据时不说“完全 1:1”。资料不足时继续完成可确定部分，明确哪些是拟合，避免无限微调或虚构背面。
- 请求 STEP/SolidWorks 时另走实体 CAD 流程；不得把高面数三角网格转封装后当成可编辑工程模型。用户只要 Blender 时不擅自扩大为工程重建。

## 可复用工具

- `scripts/compare_masks.py`：依据显式比例及基准点，比较两张黑底白形轮廓遮罩；产出叠线和轮廓指标。仅适用于投影已校准的视图，不自动猜尺度，也不是整机准确度评分。
- `assets/viewer/`：本地依赖的基础 GLB 查看器，支持旋转、六向视角、动画选择与拖动、刷新；须按产品扩展独立门按钮。
- `scripts/serve_viewer.py`：仅监听本机地址，为查看器启动 HTTP 服务。

使用单图、复用旧 CAD 或处理多页不同布局时，先读 [常见失误及处理](references/lessons.md)。

## 使用示例

“根据一张正面图和一张侧面图制作可开门的展示模型，已确认总高，背面暂无资料。”先记录尺寸来源与视图索引，用共同轮廓建立壳体和净空间，拟合未证实的背面；校准相机后逐面比对，再做真实门轴和 GLB 动画。交付 `.blend`、源码、普通 GLB、对照图和可旋转预览，并说明背面属于拟合；不能将此称为工程 CAD 或完整 1:1 复刻。

模板不含客户模型、产品尺寸、品牌贴图或私人案例图片。原生模型制作和浏览器验收必须在使用时实际执行；随包脚本通过测试不代表特定产品已经建模或验收。
