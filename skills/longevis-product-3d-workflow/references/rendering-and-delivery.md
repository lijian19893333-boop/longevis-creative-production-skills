# 渲染与交付

## 镜头设计

参考机位：左前主视觉、正面、右前、开门、内饰全景、家具与设备、天花灯光、把手或材料特写。按产品删减或更换，不为凑数量重复几乎相同的画面。

源模型按真实尺寸保留；通过机位和焦距构图。正面对比使用长焦透视或合适的正交视图，注意不要裁断底座。正交相机水平拍摄时，画面底部射线可能从地面下方发出，形成灰色条带；改用长焦透视或调整相机高度。

浅暖灰棚拍可用连续弧形背景和柔和面积光。让白色产品与背景有足够区分，保留接触阴影，避免金属高光完全死白。不要强制其他用户使用浅灰。

内饰可以在渲染场景里暂时隐藏前部遮挡，但镜头要裁掉壳体断面和结构裸边。四边检查控制屏碎片、家具切角、灯具边缘等无意带入的细节。星空顶保留清晰光点，不靠过度泛光掩盖几何。

## 从试渲染到正式图

- 先做约 600–1000 px 试图，检查代表性的外观、内饰及复杂透明件。
- 再以正式像素渲染一张，放大检查并记录耗时；低分辨率耗时不能直接当作整批耗时。
- 示例使用 Cycles、降噪、自适应采样，64 samples 是起点而非画质保证。噪点、透明件和小光源不稳定时针对性提高；不要未经检查便对全部镜头设置极高采样。
- 检查可用 GPU 后选择后端；没有兼容 GPU 时明确使用 CPU。通常一个 GPU 批次顺序渲染更易控制，多进程争抢同一 GPU 不一定提速。
- 逐张写文件和完成记录。中断后的旧 PNG 不代表本次成功；新的临时输出验证后才替换目标文件并记录哈希。
- 修改相机、材质、模型或配方后，通过配置指纹决定重渲染，不手工伪造完成记录。复用图也应明确注明来源。

## 透明件

网页 glTF 为可见性设置的低 Alpha 与 Cycles 透射叠加后，可能产生重影或不合理半透明。仅在渲染副本中评估 Alpha、Transmission、IOR 和 Roughness；保留实际门板厚度和材料要求。不要通过删除门板或把 PC 当空气来获得清晰画面。

## 成图与检查

画册图长边可从 3000–4000 px 起，具体按版面、裁切和打印尺寸决定。此次案例用了外观 3600×3000、内饰 3600×2700、特写 2400×3600；这些不是脚本固定尺寸。

提供无叠字 PNG 和高质量 JPG。总览可以加方案名和镜头标题，但与独立排版图分开。

`print_mm = pixels / dpi × 25.4`。3600 px 在 300 dpi 下对应 304.8 mm；只改 dpi 不能将低像素图变成高清图。保留 sRGB ICC；CMYK 转换需匹配印刷方、纸张与输出条件。

最终检查：逐张可打开、像素正确、ICC 与声明一致、方案及镜头数一致、文件哈希有效、ZIP CRC 正常、源模型未写改。用总览检查构图与色调，再对玻璃、金属、细缝和文字放大检查。脚本验证不替代视觉审阅。
