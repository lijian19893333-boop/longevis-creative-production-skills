# 商业叙事与事实

## 投资人要判断的内容

| 模块 | 要回答的问题 | 常见的有效证据 |
| --- | --- | --- |
| 用户与问题 | 谁在什么情境下有多大的问题 | 真实访谈、工作流程、付费或替代行为 |
| 产品与价值 | 产品怎样改变该情境 | 产品演示、清楚的功能范围、可复核使用结果 |
| 技术与差异 | 相比现有做法，价值为何成立 | 同条件测试、结构解释、能力边界 |
| 市场与切入 | 先服务谁，怎样触达 | 明确地域/时间/人群口径、可执行渠道 |
| 商业模式 | 谁付钱，付多少，交付留下多少现金 | 定价依据、成本报价、渠道条件 |
| 团队与进度 | 为什么团队能推进，已完成什么 | 人员经历、样机、版本、测试、订单、交付记录 |
| 执行与融资 | 这笔钱将解除什么限制 | 里程碑、资金用途、阶段验收及周转安排 |

不要用“颠覆”“全闭环”“巨大蓝海”替代上述证据。写不出结论时保留题目和待填项，不制作虚构的证明。

## 事实登记

在工作目录维护以下字段即可，无需自动增加正文登记页：

`信息项 / 当前表述 / 事实状态 / 来源与日期 / 正文去向 / 待补内容`

事实状态示例：

- 已有证据：具体文件或公开出处。
- 用户口述待核验：不提升为签约、收入、认证或授权。
- 规划目标：将发生的进度、销量、渠道或迭代。
- 测算假设：成本、转化率、目标人群筛选比例等。
- 界面/外观示例：设计展示，不等于产品已经上线或量产。

用于结论的必要限制留在页面；长出处、设计来源和详细解释可放备注。

## 市场与竞品

需要补外部信息时查当前可核验来源，优先行业协会、政府公开数据与厂商官方资料。按当前环境的研究技能和工具执行。

- TAM、SAM、SOM 使用同一地域、时期、货币与产品范围。一次性装机存量不能写成年度营收。
- 自上而下数据需要与自下而上的“可触达人群/渠道 × 合理转化 × 客单”交叉校验；没有依据的比例标假设。
- 各国总人数、不同场景参与者和核心付费人群不直接相加。
- 竞品既包括同类设备，也包括用户现有的替代做法。表格比较用户任务、输入输出、使用条件和购买方式，避免每项都写自己优于所有对手。
- 厂商宣传能力和同条件实测结论分开。公开未提某功能不代表该功能一定不存在。

## 现金与融资

按真实业务决定展示层级。早期硬件可先解释：

`单台现金贡献 = 实际收款 − 渠道结算 − 变动交付成本 − 获客支出`

变动交付成本可能含产品、包装、物流、售后及退货准备；税费、研发、团队和固定费用是否纳入须明确。不要把一项预算余量写成净利润。

设备销量、订单金额、交付数量、实际回款分别列示。批量生产还需考虑首付款、尾款、账期、存货和退款，不用全年收入掩盖短期现金缺口。

融资金额、股权比例和估值只有在当前项目确认后填写。若双方采用同一轮普通股投后口径，可核对：

`投后估值 = 本轮投资额 ÷ 本轮新增股权比例`

有可转债、分期交割或其他特殊条款时保留条件，不套简式。涉及具体融资条款或法律/财务判断时按当前环境要求另行核验。

融资收尾页说明金额、用途与预期里程碑即可。资金用途与总额要相等，阶段预算与采购示例不能被读成新增一笔融资。

## 缺资料时的可编辑模板

- 团队：`[姓名 / 职责 / 投入程度 / 相关经历与可核验成果]`
- 研发：`[样机 / 算法 / App阶段] [版本日期] [测试结果]`
- 用户与渠道：`[试用人数] [有效使用] [教练/机构] [订单/交付/回款]`
- 成本：`[报价日期] [报价数量] [单台成本范围] [未含项目]`
- 融资：`[本轮金额] [股权/其他方式] [资金用途] [阶段目标]`

括号内是填写位置，不是已完成事实。已获得的事实优先呈现，其余位置允许明确留空。
