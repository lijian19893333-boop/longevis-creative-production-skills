# 要求的来源、日期与范围

于 **2026-10-22** 核对国家版权局[《计算机软件著作权登记办法》官方 PDF](https://www.ncac.gov.cn/xxfb/flfg/bmgz/202410/P020241015604759788122.pdf)，重点为第九至十二条及第十七条。一般鉴别材料取源程序与一种文档首尾连续各30页，不足60页提交全部；特定情形之外，程序页至少50行、文档页至少30行。第十二条另列例外交存方式，不能自创遮盖规则。

该办法没有统一规定主要功能必须达到500汉字；这一目标应注明来自当前撰写师或表格。

实际办理时，重新查看官方现行指南和申报页面提示，记录网址、查阅日期、条款／字段、代理要求及本案处理方式。本参考不证明当前上传限制、表格、线上流程、费用、时限或某个具体版式已获接受。短代码、图形化平台、保密等特殊情况按现行官方提示与撰写师核对，其余准备继续进行。

| 项目 | 正确处理 |
|---|---|
| 工具每页50条原始非空行 | 本地排版与计数选择，仍检查实际渲染页 |
| 功能说明500汉字 | 撰写师／本项目明确要求时执行 |
| 同时提供操作与设计说明书 | 按需要或代理要求提供，不能声称统一强制 |
| APK、实机截图 | 可用于核版本和运行证据，本文不将缺失直接认定为法定驳回条件 |
| 原生 HMI 工程加脚本 | 仍需范围／导出核查，文件存在不等于全程序证明 |
| 合理日期建议 | 明确拟填，最终声明前取得事实确认 |
