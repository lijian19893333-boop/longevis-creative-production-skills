# Website Release Record

[中文版 / original bilingual template](release-record.example.md)

This is a blank template. Fill it from the current project; do not include credentials or private customer data. Every field is a placeholder and does not establish that any site has been deployed.

| Field | Value |
| --- | --- |
| Project and scope | [fill] |
| Existing authorization | [fill] |
| Source commit or package hash | [fill] |
| Current and candidate versions | [fill] |
| Target environment and public URL | [fill; no private credentials] |
| Build and start commands | [discover from project] |
| Data changes | [none or exact migration scope] |
| Backup and rollback | [private storage reference; no secrets] |
| Desktop and mobile checks | [time, viewport, result] |
| Media playback | [codec, range, actual playback] |
| DNS and TLS | [records, SAN, validity, public verification] |
| Forms, auth and routes | [actual checks] |
| Search discovery | [submitted, crawled, indexed, cited: separate statuses] |
| Release outcome | [local, staged, switched, public verified] |
| Remaining work | [owner, next action] |
