# 多轮产品复刻中有效的做法

| 反复出错的做法 | 有效替代 |
|---|---|
| 凭正面印象搭方块，随后不断补丁 | 先正/侧/俯视共享轮廓与截面，把净空间、壁厚、前门关系统一 |
| 新外壳直接罩在旧整机上 | 明确旧 CAD 复用白名单，排除旧前舱、隐藏壳体和重复底盘 |
| 用厚墙填缝，导致舱内越改越小 | 内外轮廓分别定义；门、侧壁、底板共用连接边界 |
| 把“面板凸出”做成横向弧面 | 读取侧视折线；屏幕平面保持平直，外凸来自深度和倾斜 |
| 仅正面像就交付，让用户继续找错 | 自己逐面核对、展示对应证据；改动牵涉的视图一起复核 |
| 放大缩略图，把近似颜色说成正式 UI | 提取原稿/内嵌大图，校透视，保留原颜色，检查贴图与显示面 |
| 看图中左右位置直接镜像 | 根据观察面、门面、操作面相对方向识别不同配置 |
| “开门”改成墙体透明 | 真正旋转门组，保留固定外壳；拆件另设功能 |
| 一个按钮同时打开所有门 | 支持独立门状态，确认另一扇门不重置 |
| 说右侧已打开，实际只是工具截图或排队 | 验证本地服务、页面加载和用户可访问入口；如排队就说明排队 |
| 把每个小建模块都当工程零件 | 按装配意义分件；渲染资产与实体工程 CAD 分开交付 |
| 为追求“1:1”猜隐藏机构、无止境调整 | 对有证据的几何收敛；无证据部分明确拟合，不编造工程准确度 |

本方法来自开放式圆弧舱体和封闭式矩形电冷舱的建模经验，但不继承它们的高度、截面、品牌、屏幕规格、门角度或颜色。不同产品重新建立约束；尺寸正确与投影相似是两种需要分别验证的结果。
