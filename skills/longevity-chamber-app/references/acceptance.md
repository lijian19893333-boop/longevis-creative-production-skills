# 受影响路径的验收

每项记录前置条件、操作、预期、实际结果、版本、证据及未完成部分。以下是待执行场景，不表示通过。

1. 参数最小/最大/非法输入、保存后回读、设备拒绝和超时；分别观察草稿、配置、目标和实测。
2. 页面重进、语言切换、App 重启后的配置与活动会话；不得把旧状态无条件重发。
3. 断线前/中/重连后的权威状态；演示标识、旧反馈、重复 ACK 与迟到响应。
4. 正常、手动、故障结束和各自收尾；本型号未支持的暂停或门控记为不适用。
5. 告警发生、恢复、锁存和确认；普通提示与必须阻断的故障分开。
6. 唤醒、弹窗、禁用、提交中、空数据与连接失败；核对实际屏幕触控。
7. 维护权限、输出请求与真实反馈、退出/超时恢复；仅在已授权测试环境执行。
8. 清除与升级有范围、取消、失败与恢复路径。UI 验证不等于执行真实清除或升级。

结果区分未执行、模拟、UI、通信、台架、整机及用户确认，不用一个完成勾选覆盖全部。
